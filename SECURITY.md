# Security Policy

## Supported Versions

We apply security patches to the following versions of the Fintech Analytics project:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within the Fintech Analytics platform, please do NOT report it by opening a public GitHub issue. 

Instead, report it via email to the core maintainers.

Please include:
1. The type of issue (e.g. SQL Injection, Data Exposure).
2. The location of the bug (file, URL).
3. The impact of the vulnerability.
4. Steps to reproduce.

We will try to acknowledge your report within 48 hours and provide a timeline for the resolution.
